# Support

For setup questions and reproducible bugs, use
[GitHub Issues](https://github.com/Heartkemy/mdspeak/issues). Include macOS,
Python, and MLX-Audio versions plus the exact model-free command that failed.

Do not put API keys, personal text, reference audio, or cached WAV files in a
public issue. Report security vulnerabilities through the private process in
[SECURITY.md](SECURITY.md).
