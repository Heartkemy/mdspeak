# Security policy

mdspeak is designed as a loopback-only, single-user tool. Do not expose its
local HTTP services to a network, tunnel, or shared machine.

For a vulnerability, use GitHub's **Report a vulnerability** control in this
repository's Security tab. Private reports are preferred over public issues.
Include a minimal synthetic reproduction and do not attach keys, personal text,
or reference audio.

The scope includes this repository's source, CI configuration, and documented
local-service behavior. It excludes upstream model weights and third-party
providers, although a safely reproducible integration issue is still welcome.
